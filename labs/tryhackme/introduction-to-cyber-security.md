## Goal
A beginner module on what offensive and defensive security are, and the kinds of careers available in cyber.

## What the module covers
This module generally includes:

- **Offensive Security Intro:** a first look at offensive security in a legal lab, including hacking a vulnerable online-banking application (finding a hidden page and transferring money between accounts). See the [room write-up](offensive-security-intro.md).
- **Defensive Security Intro:** an introduction to defensive security and related topics such as threat intelligence, Security Operations Centers (SOC), digital forensics and incident response (DFIR), malware analysis, and SIEM, including protecting a system by blocking an ongoing cyber attack.
- **Careers in cyber:** an overview of different careers in the field.

## What I learned
- Offensive security is about finding and using weaknesses the same way an attacker would, in a sanctioned lab.
- Defensive security is about detecting and stopping attacks, including work in a SOC and related defensive roles.
- Cybersecurity includes a range of careers on both the offensive and defensive sides.
